# 🌸 Iris Flower Classification (Machine Learning Project)

## 📌 Problem Statement

A botanical research centre aims to automate the identification of Iris flower species using machine learning instead of manual measurements, which are time-consuming and error-prone.

---

## 📊 Dataset

* Total Samples: 150
* Features:

  * Sepal Length
  * Sepal Width
  * Petal Length
  * Petal Width
* Target Classes:

  * Iris-setosa
  * Iris-versicolor
  * Iris-virginica

---

## ⚙️ Models Implemented

* K-Nearest Neighbors (KNN)
* Logistic Regression
* Naive Bayes

---

## 🧪 Experiment Setup

* Training Data: 50% of dataset
* Testing Data: 100% of dataset
* Evaluation Metrics:

  * Accuracy
  * F1 Score

---

## 📈 Results

* KNN → Best Performance
* Logistic Regression → Good Performance
* Naive Bayes → Slightly lower performance

---

## 🏆 Conclusion

K-Nearest Neighbors (KNN) performed the best due to the small, clean, and well-separated nature of the Iris dataset. However, KNN may not scale well for large datasets due to high computational cost.
